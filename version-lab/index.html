Each historical app below is built from the original Git tree at the stated commit. The files are copied byte-for-byte at deployment; the lab does not recreate an old app from today's files or from today's version.json.

Versions 1.0.0–1.3.0 pre-date semantic version files, so their labels are reconstructed milestones. Their snapshots are still the original files from the listed commits. Cloud services are not time-travelled. The historical HTML/JS/CSS/data are exact, but old sync endpoints, Firebase Authentication users and Firestore rules may have changed or disappeared. Use the snapshots to inspect and exercise the historical UI/local behaviour; do not assume historical cloud sync will still work against today's backend.

What is usable? Static school data, navigation, filters, cards, calendar UI and local-storage behaviour come from the original files and should be meaningful to inspect. Cloud-backed behaviour is only historically accurate at the code level; the live backend is today's backend. For that reason Version Lab is an audit/regression tool, not a promise that every retired cloud workflow can still authenticate or write.
